## Сборка и запуск тестов

Сборка в режиме Release:

```bash
cmake -S msgfmt -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
ctest --test-dir build
```

Сборка с санитайзерами:

```bash
cmake -S msgfmt -B build_asan -DCMAKE_CXX_FLAGS="-fsanitize=address,undefined -g"
cmake --build build_asan
ctest --test-dir build_asan
```

## Использование

### Разбор разметки

Без аргументов программа читает входной поток из `stdin` и выводит JSON-объект в `stdout`:

```bash
printf 'Привет, **мир**!' | ./build/msgfmt
```

Вывод:

```json
{"text": "Привет, мир!", "ranges": [{"style": "bold", "offset": 8, "length": 3, "url": ""}]}
```

### Экранирование текста

С аргументом `escape` программа предваряет все служебные символы (`*`, `_`, `` ` ``, `[`, `]`, `(`, `)`, `\`) обратным слешем:

```bash
printf '2 * 3' | ./build/msgfmt escape
```

Вывод:

```text
2 \* 3
```

При подаче некорректной последовательности UTF-8 оба режима выводят `{"error": "invalid_utf8"}` и завершаются с кодом возврата `2`.

## Принятые решения

1. **Однопроходный разбор и вложенность**: разбор идёт слева направо. При встрече открывающего маркера проверяется наличие парного закрывающего маркера в текущем диапазоне. Если закрывающий маркер найден, внутренний фрагмент разбирается с учётом уже открытых стилей, что исключает повторное открытие того же стиля и частичные пересечения интервалов.
2. В строке `**жирный _и курсив_**` закрывающее подчёркивание стоит после слова `курсив` (перед ним непробельный символ `в`, после него не буква и не цифра `*`). Согласно пункту 3.5 (правила 3 и 5), диапазон `italic` охватывает `и курсив` (`offset = 7, length = 8`), тогда как `offset = 7, length = 1` из примера должен получаться на входе `**жирный _и_ курсив**`.

## Известные ограничения

- Поддерживаются только четыре стиля из спецификации - `bold`, `italic`, `code`, `link`.
- Текст внутри квадратных скобок ссылки `[текст](url)` не может содержать символ `]`, а URL не может содержать пробельные символы и `)`.
- Проверка границ слов для стиля `italic` опирается на базовые диапазоны букв и цифр Unicode.
